# kitty — шпаргалка по клавишам

> Модификатор `kitty_mod` = **Ctrl + Shift**

---

## 📋 Буфер обмена

| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+C` | Копировать |
| `Ctrl+Shift+V` | Вставить |

---

## 📜 Скроллбэк

| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+↑` | Строка вверх |
| `Ctrl+Shift+↓` | Строка вниз |
| `Ctrl+Shift+Page Up` | Страница вверх |
| `Ctrl+Shift+Page Down` | Страница вниз |
| `Ctrl+Shift+Home` | В начало |
| `Ctrl+Shift+End` | В конец |
| `Ctrl+Shift+H` | Открыть скроллбэк в pager |

---

## 🔠 Размер шрифта

| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+=` | Увеличить |
| `Ctrl+Shift+-` | Уменьшить |
| `Ctrl+Shift+0` | Сбросить |

---

## 🗂 Вкладки

| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+T` | Новая вкладка (в текущей папке) |
| `Ctrl+Shift+W` | Закрыть вкладку |
| `Ctrl+Shift+→` | Следующая вкладка |
| `Ctrl+Shift+←` | Предыдущая вкладка |
| `Ctrl+Shift+1..5` | Перейти к вкладке 1–5 |

---

## 🪟 Окна (сплиты)

| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+Enter` | Новое окно (в текущей папке) |
| `Ctrl+Shift+D` | Закрыть окно |
| `Ctrl+Shift+]` | Следующее окно |
| `Ctrl+Shift+[` | Предыдущее окно |
| `Ctrl+Shift+L` | Следующий layout |

**Доступные layouts:** `tall` · `fat` · `grid` · `stack`

---

## 🔍 Hints (захват текста)

| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+E` | Hints — открыть URL |
| `Ctrl+Shift+P, F` | Захватить путь из экрана |
| `Ctrl+Shift+P, L` | Захватить строку из экрана |

---

## 🌐 Прочее

| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+U` | Ввод Unicode символа |
| `Ctrl+Shift+F11` | Полноэкранный режим |
| `Ctrl+Shift+F5` | Перезагрузить конфиг |
