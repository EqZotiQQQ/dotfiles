# Тема рабочего стола

## Выбор пресета

Выбрать тему, сохранить выбор в `~/.config/theme/preset.json` и сразу перезагрузить оформление:

```bash
~/.local/bin/theme-apply vaporwave
~/.local/bin/theme-apply --list
```

Без аргумента `theme-apply` применяет уже сохранённый выбор.
Можно также вручную указать пресет в `~/.config/theme/preset.json`:

```json
{
  "preset": "asiimov"
}
```

- `asiimov` — белые панели, графитовые детали и оранжевые акценты в стиле Asiimov из CS.
- `bloodsport` — красно-оранжевая, чёрная и белая палитра с золотистыми акцентами.
- `vaporwave` — фиолетовый и бирюзовый на тёмно-фиолетовом фоне.
- `deep-ocean` — голубой и коралловый на глубоком синем фоне.
- `forest-copper` — медный и шалфейный на зелёно-чёрном фоне.
- `graphite-lime` — лаймовый и холодный серый на графитовом фоне.
- `burgundy-gold` — золотистый и розовый на тёмном бордовом фоне.
- `arctic` — ледяной голубой и лавандовый на тёмном сине-сером фоне.

После сохранения выполните внутри Hyprland:

```bash
~/.local/bin/theme-apply --check  # проверить пресет, ничего не меняя
~/.local/bin/theme-apply          # записать настройки и применить к рабочему столу
```

Изменение `preset.json` само по себе не применяется: нужен `theme-apply`.
`theme-apply arctic --check` проверяет указанный пресет без записи выбора и конфигов;
`theme-apply arctic --files-only` сохраняет выбор и конфиги без перезапуска приложений.
Список `--list` также ничего не меняет. Ошибочное имя не заменяет сохранённый выбор.
Команда обновляет бар, AI Limits, spectrum, рамки окон, уведомления, proctree,
Kitty, wofi, обои всех мониторов и локскрин. Quickshell перечитывает JSON сам;
Hyprland и Kitty получают перезагрузку конфига, работающий proctree перезапускается.
wofi и локскрин читают новые настройки при следующем открытии.
Команда не запускает proctree, если он был выключен.

Размеры, расположение, шрифты и анимации из `theme.json`, а также геометрия,
периоды опроса и остальные настройки proctree сохраняются. Меняются цвета,
обои, палитра spectrum и выбор общего локскрина. Отдельный выбор через `lock-theme`
будет заменён при следующем применении пресета рабочего стола.

Без графического сеанса используйте `theme-apply --files-only`: он запишет файлы,
не перезапуская приложения. Полное оформление будет загружено при следующем входе.
Неизвестный пресет, неверные цвета, отсутствие обоев или ожидаемых полей конфига
дают ошибку до записи. Ошибка перезагрузки приложения также возвращает ненулевой
код; уже записанные конфиги при этом сохраняются — устраните причину и повторите команду.

## Где менять цвета

Файлы [`presets/*.json`](presets) содержат палитру `colors`,
16 ANSI-цветов `terminal`, имя файла `wallpaper` из `~/Pictures/wallpapers`
и список `spectrum` — минимум два имени из `colors` или цвета `#RRGGBB`,
от тихих участков к громким. В новых схемах spectrum переходит от тёмной подложки
через главный акцент к дополнительному; у Asiimov и Bloodsport сохранена прежняя палитра.
Это источник цветов для `theme-apply`, который обновляет существующие файлы на месте,
сохраняя симлинки и файловые наблюдатели Quickshell.

| Файл | Что получает |
|---|---|
| [`theme.json`](theme.json) | активную палитру, `name`, `wallpaper`, цвет подложки виджетов, цвета spectrum, `lock.theme` |
| [`proctree/config.yaml`](../proctree/config.yaml) | цвета дерева, подписей, сеток и графиков |
| [`kitty/theme.conf`](../kitty/theme.conf) | фон, текст, курсор, вкладки и ANSI-палитру |
| [`wofi/style.css`](../wofi/style.css) | объявления цветов в начале файла, без изменения геометрии |
| [`hypr/hyprpaper.conf`](../hypr/hyprpaper.conf) | постоянные обои выбранного пресета |

`theme.json` читают Quickshell (`common/Theme.qml`), Hyprland (`hypr/theme.lua`),
`mako-theme` и локскрин. Все параметры, кроме перечисленных полей пресета,
по-прежнему редактируются прямо в `theme.json`; их описание ниже.
Ручные правки цветов в перечисленных файлах заменяются при `theme-apply`.

Палитра wofi встроена в `style.css`: wofi загружает CSS из памяти, поэтому
относительный `@import` ищет файл в каталоге запуска и оставляет фон без цвета.
Фон окна wofi имеет 40% прозрачности (`alpha(@surface, 0.6)`) во всех пресетах.

Kitty (с любой командой внутри), Codex/ChatGPT (класс окна `Chatgpt`), VS Code,
Dolphin (`org.kde.dolphin`) и Obsidian (`md.obsidian.Obsidian`)
имеют непрозрачность 90% в фокусе и 80% без фокуса. Правила находятся в
[`hyprland.lua`](../hypr/hyprland.lua), размытие включено в Hyprland,
его сила задаётся `blur.size` и `blur.passes` в `theme.json`.
Прозрачность применяется ко всему окну, включая текст.

Проверка и установка из корня репозитория (для теста нужен Lua):

```bash
python3 -m unittest discover -s tests -p 'test_window_opacity.py' -v
./dot -s -f
Hyprland --verify-config
hyprctl reload
```

Вручную переключите фокус между Kitty, Codex, Dolphin и Obsidian: окна должны менять
прозрачность, а фон под ними — оставаться размытым. Выход из Neovim в оболочку
больше не отключает прозрачность Kitty. Перезапуск приложений не нужен.

Локскрин всех пресетов использует один QML-файл в каталоге
`lockscreen/themes/bloodsport` (имя сохранено для совместимости с предыдущей темой).
Он читает цвета и имя обоев из активного JSON; копий кода для каждого пресета нет.
`lock --preview` показывает активное оформление без блокировки сеанса.

## Установка и проверка

Из корня репозитория, внутри графического сеанса:

```bash
./dot -s -f
~/.local/bin/theme-apply
```

Для самого переключателя достаточно Python 3 из стандартной установки dotfiles,
без дополнительных Python-пакетов. Для применения нужны установленные компоненты
рабочего стола: Hyprland, hyprpaper, mako и `pkill`.
Локскрин использует qylock (`lock --fetch` при первой установке).

```bash
python3 -m unittest discover -s tests -p 'test_theme_presets.py' -v
python3 -m unittest discover -s tests -p 'test_bloodsport_lock.py' -v
python3 -m unittest discover -s tests -p 'test_ai_limits*.py' -v
python3 -m unittest discover -s tests -p 'test_widget_reveal.py' -v
Hyprland --verify-config
```

Тесты пресетов работают в временных каталогах и не меняют рабочий стол:
проверяют все восемь пресетов, выбор по имени, список, проверку без записи,
переключение туда и обратно, сохранение геометрии и симлинков,
отказ до записи при неверных данных и команды применения с имитацией процессов.
Проверка wofi загружает CSS из памяти через GTK 3 и проверяет цвет и непрозрачность
фона всех пресетов; нужны PyGObject, GTK 3 и графический сеанс.
Тест локскрина проверяет обои всех пресетов, пустой пароль, повторный ввод во время
проверки и восстановление после отказа. PAM не вызывается и сеанс не блокируется.
Для QML нужен `qs`; тестам настольных виджетов требуется Wayland.

## Ключи

- `colors` — палитра в духе Material You. `on*` — цвет текста/иконок поверх соответствующей заливки.
  - `primary` — акцент: активный воркспейс, рамка активного окна, индикаторы, шкалы.
  - `primaryContainer` / `onPrimaryContainer` — фон и текст выбранного/открытого (модуль с открытым поповером).
  - `secondary`, `tertiary` — второстепенные акценты (шкалы, выходные в календаре, «не беспокоить»).
  - `surface` — фон островов бара; `surfaceHigh` — плитки дока, дорожки шкал.
  - `onSurface`, `onSurfaceVariant` — основной и приглушённый текст.
  - `outline`, `outlineVariant` — разделители, рамки неактивных окон.
  - `error` — ошибки, перегрев.
- `bar.position` — край экрана для бара и полосы spectrum за ним: `top`, `bottom`, `left`, `right`.
- `bar.flush` — `true`: острова бара стоят вплотную к краю экрана, крайние — в его углах (`barMargin` = 0), док по-прежнему
  по центру; углы прямые: `islandRadius`, `tileRadius`, `chipRadius` считаются нулевыми (бар, поповеры, обзор воркспейсов).
  Окна Hyprland и mako это не трогает — у них `shape.rounding`.
- `widgetReveal` — совместное появление AI Limits и proctree поверх окон при упоре курсора в верхний край своего монитора.
  - `mode`: `"delay"` — задержка у края; `"pressure"` — накопленное движение мыши вверх после упора.
  - `delayMs`: задержка до начала появления в режиме `delay`, мс; по умолчанию `450`.
  - `pressureThreshold`: сколько относительного движения вверх нужно для полного появления в режиме
    `pressure`; по умолчанию `120`. Меньше — легче проявить. Используются движения без ускорения;
    чувствительность зависит от DPI мыши. Само движение до края не засчитывается.
  - `fadeMs`: длительность плавного изменения прозрачности, мс; по умолчанию `360`.
    При изменении давления анимация сохраняет текущую скорость; при смене направления
    начинает движение в обратную сторону с нулевой скорости, без выброса прозрачности за 0…1.
  - `gap`: зазор между внешними границами proctree и AI Limits в логических пикселях;
    по умолчанию `20`, допустимо 0…4096. AI Limits находится ниже proctree, правые края совпадают.
    Положение в переднем слое пересчитывается в каждом кадре с учётом роста содержимого и отступов.
  - `backdrop` — общий стиль подложек proctree и AI Limits. Бокс proctree охватывает
    фактические границы дерева, подписей и панелей, включая ореолы текста;
    пустая часть поверхности в бокс не входит. AI Limits использует те же отступы, цвет и блюр.
    - `color`: цвет `#rrggbb`; по умолчанию тёмно-серый `#242424`.
    - `opacity`: непрозрачность 0…1; по умолчанию `0.65`.
    - `padding`: отступ вокруг содержимого в логических пикселях; по умолчанию `16`, допустимо 0…4096.
    - `radius`: радиус скругления в логических пикселях; по умолчанию `18`, допустимо 0…4096.
    - `blur`: включение размытия окна под боксом; по умолчанию `true`.
    - `blurOpacity`: степень проявления размытия 0…1; по умолчанию `0.35`.
    Сила самого фильтра задаётся общими `blur.size` и `blur.passes` ниже.
    Цвет, прозрачность и геометрия подложки применяются сразу; для изменения
    `blur.size`/`blur.passes` нужен `hyprctl reload`.
    Подложка и блюр проявляются вместе с содержимым. Чтобы убрать подложку полностью,
    задайте `opacity: 0` и `blur: false`.
  - Настройки применяются сразу. Уход от края сбрасывает задержку и давление, виджет плавно
    возвращается под окна. proctree использует тот же прогресс появления, включая дерево и панели.
    Передние копии, их подложки и блюр ограничены рабочей областью вне бара: отступы
    не заходят под полупрозрачные плитки приложений и компактные виджеты статуса.
    Клики проходят насквозь, клавиатурный фокус не меняется.
    При зажатой кнопке мыши, блокировке сеанса и захвате курсора эффект выключается.
  - Поля режима и все поля `backdrop` обязательны: `delayMs` и `fadeMs` — целые числа ≥ 0,
    `pressureThreshold` — число > 0, `gap` — число 0…4096. Ошибка настроек отключает эффект с уведомлением.
    proctree должен быть пересобран с поддержкой `layer_shell.visible_bounds: true`;
    без опубликованных границ передняя группа и AI Limits скрыты, фиксированные координаты не подставляются.
    Детектор — локальный плагин Hyprland 0.56; сборка и проверка описаны в
    [основном README](../../../README.md#виджеты-поверх-окон-у-верхнего-края).
- `opacity.panel` — непрозрачность островов бара в покое (без размытия: сквозь них виден spectrum);
  `opacity.popout` — непрозрачность острова, пока открыт поповер (окна под ним не мешают тексту),
  фона уведомлений mako. Подложки AI Limits и proctree задаёт `widgetReveal.backdrop`.
- `shape` — `rounding`, `border`, `gapsIn`, `gapsOut` для окон Hyprland (`rounding`, `border` — и для уведомлений mako); `barSize` (толщина бара; модули, плитки дока и воркспейсы — ¾ от неё), `barMargin`,
  `islandRadius`, `tileRadius`, `chipRadius` для бара.
- `blur` — общая сила размытия Hyprland для окон и подложек виджетов (`size`, `passes`); на бар не действует.
- `motion` — `curve`: кривая Безье `[x1, y1, x2, y2]` для окон Hyprland и анимаций бара
  кроме поповеров и подсветки выбранного модуля (y > 1 даёт лёгкий «перелёт»); `durationMs` — длительность анимаций бара; `hyprSpeed` — скорость
  анимации окон Hyprland; `windowPopin` — с какого масштаба окно «выпрыгивает».
  Поповеры ЦП, температуры, памяти и остальных модулей раскрываются от границ выбранного модуля
  и сворачиваются обратно к нему. Размер и положение меняются вместе за `durationMs` (сейчас 460 мс),
  с кривой `InOutCubic`: медленно в начале и конце, быстро в середине, без перелёта.
  При переходе к соседнему модулю уже раскрытый бокс и общая подложка подсветки плавно переезжают к нему.
  Подложка подстраивается под размер модуля; цвета иконки и текста меняются плавно за то же время.
  При открытии и закрытии подсветка проявляется и гаснет на месте. Быстрое переключение
  продолжает движение из текущего положения без скачка; сам выбор по клику происходит сразу.
  Бокс может выступать за начало острова статуса; положение ограничивается краем экрана.
  Для открытия курсор должен оставаться над модулем 120 мс. Уход за пределы модуля и раскрытого
  бокса закрывает его через 350 мс, в том числе при упоре в верхний край экрана.
  Возврат курсора отменяет закрытие; закреплённый кликом бокс остаётся открытым до повторного клика.
- `fonts` — `ui` (бар, уведомления mako), `mono` (числа в баре), `icons` (Nerd Font с иконками), `size` (бар, px).
  Те же `ui` / `mono` стоят в `~/.config/fontconfig/fonts.conf` как `sans-serif` / `monospace` — для остальных
  программ; меняя шрифт здесь, поменяй и там.
- `spectrum` — `size`: толщина полосы spectrum за баром, px; `colors`: цвета полос от тихих к громким,
  имена из `colors` или `"#rrggbb"`.
- `lock.theme` — тема локскрина: имя каталога в `~/.config/lockscreen/themes/` или тема qylock.
  Проще всего менять командой `lock-theme` (список всех тем со ссылками на превью → скачать → включить);
  `lock --preview [имя]` — посмотреть без блокировки.
